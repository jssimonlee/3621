# 폼텍 3621 라벨 인쇄

폼텍 3621 화일 인덱스 라벨을 브라우저에서 작성하고 미리 확인한 뒤 인쇄하는 정적 웹사이트입니다. 서버나 데이터베이스가 필요하지 않아 GitHub Pages에서 바로 운영할 수 있습니다.

## 주요 기능

- 한 줄에 하나씩 라벨 내용을 직접 입력하거나 여러 줄을 한꺼번에 붙여 넣기
- 모든 라벨 끝에 ` ~`를 한 번에 추가
- 이미 사용한 라벨지를 재활용할 수 있도록 첫 인쇄 위치 지정
- 가로 우선 또는 세로 우선 채우기 순서 선택
- 각 내용을 한 칸씩 또는 같은 내용으로 두 칸씩 연속 배치
- 실제 A4 용지 비율을 유지한 인쇄 미리보기와 페이지 이동
- 글자가 셀을 벗어나는 라벨을 주황색으로 표시
- 셀별 또는 여러 셀의 글자 크기를 `− / +`로 조절
- 글꼴, 기본 글자 크기, 왼쪽 여백 및 프린터 위치 보정 설정
- 입력 내용과 설정을 브라우저에 자동 저장

## 사용 방법

### 1. 라벨 내용 입력

왼쪽 입력창에 한 줄당 라벨 하나를 입력합니다. 빈 줄은 라벨 수에서 제외됩니다.

입력창 위의 `라벨 끝에 붙이기`를 누르면 내용이 있는 모든 줄 끝에 ` ~`가 추가됩니다. 이미 `~`로 끝나는 줄에는 중복으로 붙지 않습니다.

### 2. 배치 방식 선택

- `첫 라벨 위치`: 이미 사용한 칸을 건너뛰고 선택한 위치부터 인쇄합니다.
- `2개씩`: 각 라벨을 같은 내용과 글자 크기로 두 칸씩 연속해서 배치합니다. 복사된 두 칸의 글자 크기는 함께 조절됩니다.
- `라벨 채우는 순서`: 설정에서 다음 중 하나를 선택합니다.
  - 가로 우선: 왼쪽 → 오른쪽 → 다음 행
  - 세로 우선: 왼쪽 열 전체 → 오른쪽 열

### 3. 글자 넘침 수정

글자가 셀을 벗어나면 해당 셀이 주황색으로 표시됩니다. 셀을 선택하면 나타나는 `− / +` 버튼으로 글자 크기를 조절합니다.

주황색 셀이 2개 이상이면 `주황색 모두 선택` 버튼을 사용해 한꺼번에 조절할 수 있습니다.

일반 셀 선택 방법은 Windows의 파일 선택 방식과 비슷합니다.

- 클릭: 셀 하나 선택
- `Ctrl`+클릭: 셀 추가 선택 또는 선택 해제
- `Shift`+클릭: 시작 셀부터 클릭한 셀까지 범위 선택
- `Ctrl`+`A`: 모든 라벨 선택(미리보기 영역에 포커스가 있을 때)
- 빈 셀이나 용지 바깥 클릭: 현재 선택 해제

### 4. 인쇄

상단의 `인쇄`를 누르면 확인 안내가 나온 뒤 크롬·엣지의 인쇄창이 열립니다. 정확한 위치에 출력하려면 인쇄창에서 다음 값을 확인하세요.

- 용지 크기: A4
- 방향: 세로
- 여백: 없음
- 배율: 맞춤설정 100
- 시트당 페이지 수: 1
- 머리글과 바닥글: 사용 안 함
- 컬러: 필요한 경우 흑백

웹사이트는 A4·세로·여백 없음에 맞춘 인쇄용 CSS를 사용하지만, 브라우저 보안 정책상 프린터 선택이나 인쇄창의 여백·배율·컬러 값을 직접 변경할 수는 없습니다. 프린터나 브라우저가 바뀌면 위 설정을 다시 확인하세요.

## 설정

### 글꼴

기본 설정은 HY견고딕이 컴퓨터에 설치되어 있으면 사용하고, 없으면 Noto Sans KR Bold를 사용합니다. 모든 글꼴의 최초 기본 크기는 22pt입니다. 사용자가 글자 크기를 직접 변경한 뒤에는 해당 값이 유지됩니다.

기본 글꼴 목록에는 다음 항목이 항상 표시됩니다.

- 기본 — HY견고딕
- 노토 산스 한글(Noto Sans KR)
- 맑은 고딕
- HY견고딕

글꼴 목록에서 `이 컴퓨터 글꼴 불러오기…`를 선택하면 설치된 다른 글꼴을 추가로 표시합니다. 크롬·엣지가 처음 한 번 로컬 글꼴 접근 허용 여부를 물을 수 있습니다. Windows가 영문 이름으로 제공하는 주요 한글 글꼴은 바탕, 돋움, 굴림, 궁서 등의 한글 이름을 함께 표시합니다.

HY견고딕 파일은 이 저장소에 포함하거나 웹으로 배포하지 않습니다. 사용 중인 HY견고딕의 라이선스 조건은 해당 글꼴을 제공한 제품 또는 판매처에서 확인해야 합니다.

### 위치 보정

프린터마다 급지 위치에 차이가 있으므로 먼저 일반 A4 용지에 시험 인쇄하는 것을 권장합니다. 전체 라벨이 같은 방향으로 밀리면 설정의 `좌우 보정`과 `상하 보정` 값을 0.5mm 단위로 조절할 수 있습니다.

## 폼텍 3621 규격

- 용지: A4 210 × 297mm
- 배열: 2열 × 18행, 총 36칸
- 라벨 한 칸: 95 × 14mm
- 좌우 여백: 9mm
- 상단 여백: 22.5mm
- 열 사이 간격: 2mm

## 로컬 실행

정적 파일만 사용하므로 `index.html`을 직접 열 수 있습니다. 로컬 웹 서버를 사용하려면 프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
python -m http.server 8000
```

그런 다음 브라우저에서 `http://localhost:8000`을 엽니다.

## GitHub Pages 배포

1. GitHub 저장소의 `Settings → Pages`로 이동합니다.
2. `Build and deployment`의 Source를 `Deploy from a branch`로 선택합니다.
3. `main` 브랜치와 `/ (root)` 폴더를 선택하고 저장합니다.

이 저장소를 GitHub Pages로 배포하면 기본 주소는 다음과 같습니다.

`https://jssimonlee.github.io/3621/`

## 파일 구성

- `index.html`: 화면 구조와 인쇄 안내
- `styles.css`: 화면·미리보기·A4 인쇄 스타일
- `app.js`: 입력, 배치, 선택, 글꼴 및 인쇄 동작
